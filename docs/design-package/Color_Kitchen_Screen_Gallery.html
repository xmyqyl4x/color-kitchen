02 Palette Studio

Create and keep what works. Visible generation, color locks and swatch actions support quick iteration. The neutral labels remain readable independently of swatch color. The shared ribbon carries the same palette into checking, preview and export.

03 Palette Gallery

Discover without losing context. Search and filters narrow the original palette collection. Cards expose exact values and clear reuse actions. Catalog labels and counts are illustrative; production popularity must reflect actual measured data.

04 Image to Palette

Extract locally. The image and its extracted colors appear together. The sample artwork is original. Upload processing is designed to remain on the device, and this private work surface does not contain a programmatic ad slot.

05 Contrast Lab

Check a specific pair. The initial pair computes to 3.276012311465193, shown as 3.28:1. It fails AA normal text and passes AA large text. The proposed text color #3E6452 reaches 6.127462422138969 on #F8F5EF, shown as 6.13:1.

06 Design Preview

Apply colors to real roles. A small original template turns abstract swatches into background, surface, text and accent roles. Previewing a role pairing is distinct from certifying the whole design. Changes remain reversible.

07 Color Inspector

Inspect and convert. An individual color has explicit values, variants and copy actions. Screen picking is progressive enhancement, with manual entry and image sampling as fallbacks. Original wide-gamut values and sRGB fallbacks remain distinguishable.

Back to screen list

08 Tailwind Studio

Export for the chosen Tailwind version. The shade scale has explicit steps and a version selector. v4 uses CSS theme variables; v3 requires its configuration form. The interface preview should validate actual foreground and background pairings.

Back to screen list

09 Color Guide

Guide creation with honest modes. The conversation is explicitly an illustrative sample. The full design includes free hosted AI conversation and a separate local quick-suggestion mode. Deterministic code validates color values and computes contrast; no ad appears beside private chat.

Back to screen list

10 Color Atlas

Find a named color. Color Atlas combines search, filters, readable values and source information. Nearest descriptive names must be identified as suggestions. Selecting a color leads into the same inspector and palette workflow.

Back to screen list

11 Gradient Gallery

Browse reusable gradient recipes. Gradient cards show their visual direction and an immediate editing path. Production recipes must preserve stop positions, interpolation and provenance. Discovery should not require opening several dialogs to copy or edit.

Back to screen list

12 Gradient Studio

Author a continuous gradient. Controls expose gradient type, direction, stops and code. Numerical position fields complement dragging. Transparent-stop interpolation and exported CSS must agree with the preview.

Back to screen list

13 Gradient Steps

Turn a gradient into discrete colors. A step count produces a sampled palette with both endpoints included. This is a distinct job from editing a continuous gradient. Sample positions and interpolation settings belong in the document state.

Back to screen list

14 Moodboard Maker

Compose a clean moodboard. Original artwork, title and palette become a simple board. User images stay local. The export includes the board itself, without application controls, advertising or a watermark.

Back to screen list

15 Font Library

Choose fonts with provenance. The library separates browsing, preview and licensing details. These visuals use system substitutes for named catalog fonts; production must load the actual licensed font assets and retain their required notices.

Back to screen list

16 Type Playground

Preserve styled text and readable alternatives. Typography and Styled text are separate modes. Decorative Unicode output has a plain-text copy alongside it and an explanation of reading and compatibility limits. The feature does not create a downloadable font file.

Back to screen list

17 Browser Companion

Capture only when asked. The Browser Companion concept explains invoked page-color extraction, local values and explicit handoff to the website. No store approval or availability is claimed. Production permission requests must match implemented behavior.

Back to screen list

18 My Collection and Export

Save on this device and export. My Collection is local, with a clear backup route. The shared drawer exposes free formats and token options. The private collection and export surface contains no programmatic advertising.

Back to screen list

19 Mobile Palette Studio

Make the mobile task reachable. Stacked swatches preserve readable labels and useful touch targets. Locking, copying and the main action remain explicit. The action bar is part of the design; production must verify that it does not hide focused controls or the keyboard.

Back to screen list

20 Mobile Cookie Preferences

Make consent a real choice. Accept optional and Reject optional have equal prominence. Optional categories have independent controls, essential storage is explained, and tools remain available either way. A production implementation must use the chosen consent platform correctly.
